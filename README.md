# 🎥 Cinematic Web CCTV

A lightweight, custom HTML/JS web application that instantly turns any old smartphone into a secure, peer-to-peer CCTV monitor. 

No apps, no servers, no subscriptions. Just a direct WebRTC connection between two browsers.

## ✨ Features
* **Zero Installation:** Runs entirely in modern mobile and desktop browsers.
* **Peer-to-Peer Encryption:** Video streams directly from camera to monitor using PeerJS.
* **Cross-Network Support:** Uses Google STUN servers to connect devices across different Wi-Fi or cellular networks.
* **Cinematic UI:** Features a dynamic gradient background and frosted glassmorphism interface.

## 🚀 How to Use
1. Open the live site on your old phone (the camera).
2. Enter a unique Room ID and tap **Initialize Camera**.
3. Open the site on your current device (the viewer).
4. Enter the *exact same* Room ID and tap **Connect Monitor**.
